Case study · Cliente real

Clínica Pepe Soler

Rediseño web + mejora de solicitud de cita

Rediseño y desarrollo de una web sanitaria responsive para una clínica local, incorporando un flujo de solicitud de cita por WhatsApp sin backend que mejora el primer contacto sin alterar el sistema manual de gestión del cliente.

Ver web
Cliente
Clínica sanitaria local
Sector
Osteopatía y fisioterapia
Stack
React · Vite · CSS · WhatsApp links

Problema

Actualizar la web sin imponer una agenda digital.

La clínica necesitaba actualizar su presencia digital y mejorar la experiencia en móvil. Además, el contacto para pedir cita dependía de llamadas o mensajes poco estructurados, pero el cliente no quería implantar una agenda online porque trabaja cómodamente con un sistema manual en papel.

  • Web anterior poco actual.
  • Experiencia responsive mejorable.
  • Contacto para cita poco estructurado.
  • Necesidad de mejorar sin digitalizar la agenda.

Punto de partida

La web anterior funcionaba, pero ya no representaba bien la calidad de la clínica.

01

Jerarquía visual débil

El contenido era correcto, pero competía con banners, imágenes y botones tratados como piezas sueltas.

02

Estructura poco flexible

La interfaz se sentía anclada a otra época, con navegación y galerías pensadas sobre todo para desktop.

03

Contacto con fricción

Transmitía menos confianza que la consulta real y no guiaba bien al paciente para preparar una cita.

Objetivos

Resolver lo importante con una solución pequeña y útil.

01

Imagen actual

Modernizar la presencia visual de la clínica sin perder cercanía ni confianza sanitaria.

02

Mejor responsive

Ordenar navegación, contenido y CTAs para que la experiencia móvil fuera clara y rápida.

03

Cita sin backend

Facilitar la solicitud de cita sin calendario online, base de datos ni cambios operativos internos.

Solución

Una web sobria que mejora el contacto sin cambiar el trabajo interno.

Se diseñó una web clara, sobria y responsive, centrada en transmitir confianza y hacer fácil el contacto. En lugar de crear un sistema de reservas, se añadió un preparador de mensaje para WhatsApp que ayuda al paciente a enviar una solicitud más completa, manteniendo intacto el proceso interno de la clínica.

  • Rediseño visual completo.
  • Secciones claras: Pepe Soler, equipo, tratamientos, clínica y contacto.
  • Tratamientos, navegación y CTAs preparados para lectura rápida en móvil.
  • CTAs visibles para cita, llamada, email y cómo llegar.
  • Preparador de cita conectado a WhatsApp.
  • Sin backend ni almacenamiento de datos.

Flujo de cita

Un preparador de mensaje, no una reserva automática.

La solución mejora la calidad del primer contacto sin automatizar la agenda. La clínica recibe mensajes más claros y sigue gestionando las citas manualmente.

  1. 1

    El usuario pulsa “Reservar cita”.

  2. 2

    Completa motivo, tratamiento orientativo, horario y comentario.

  3. 3

    WhatsApp se abre con el mensaje preparado.

Decisiones técnicas

Tecnología suficiente para el problema real.

React + Vite para componentizar secciones y estados interactivos.
CSS custom responsive para controlar layout, ritmo y adaptación móvil.
Modal de cita sin backend, sin base de datos y sin reservas automáticas.
WhatsApp deep links para enviar el mensaje preparado al canal que ya usa el cliente.
Eliminación del iframe de Google Maps para reducir carga.
Enlace directo a Google Maps para “Cómo llegar”.
Menú móvil, CTA flotante y jerarquía preparada para escaneo rápido.

Resultado

Una mejora digital compatible con la forma real de trabajar del cliente.

El resultado es una web más moderna, rápida y útil para pacientes, con una experiencia de contacto más clara. El cliente mantiene su flujo de trabajo manual, pero la web ahora reduce fricción y estructura mejor las solicitudes de cita.

  • Presencia digital más profesional.
  • Mejor experiencia móvil.
  • Solicitudes de cita más completas.
  • Sin complejidad operativa añadida.
  • Solución adaptada al contexto real del cliente.
